= Generating vertical files

Each `<CORPUS>/vertical/source` file is built from the module `.vert.tsv` data
with https://github.com/KIParla/tools[KIParla/tools]. The metadata is translated
to Italian first, with the same repository. Run the commands from the KIParla
root directory (with `tools/`, the module checkouts and this repository as
siblings).

The three scripts involved:

[cols="1,3", options="header"]
|===
| Script | Role

| `translate_metadata.py` | English → Italian value translation of one module's `conversations.tsv` / `participants.tsv`
| `merge_metadata.py`     | Merge module metadata into one collection-level set (for the `KIParla` corpus)
| `tsv2vert_v2.py`        | Render `.vert.tsv` + translated metadata to the NoSketch vertical format
|===

== Single module

Example for `KIP` (repeat for `KIPasti`, `ParlaBO`, `ParlaTO`, `ParlaBZ`):

[source,bash]
----
python tools/translate_metadata.py \
    --input-dir KIP/metadata \
    --output-dir KIParla-NoSketch-Data/metadata/KIP \
    --translations KIParla-NoSketch-Data/translations.tsv

python tools/tsv2vert_v2.py \
    --base-url http://localhost:10071/corpus \
    --artifacts-base-url https://kiparla.github.io/KIParla-artifacts \
    KIParla-NoSketch-Data/metadata/KIP/conversations.tsv \
    KIParla-NoSketch-Data/metadata/KIP/participants.tsv \
    KIP/tsv/*.vert.tsv > KIParla-NoSketch-Data/KIP/vertical/source
----

== KIParla collection

The aggregated `KIParla` corpus merges every module, then translates the merged
metadata:

[source,bash]
----
python tools/merge_metadata.py \
    --modules KIP KIPasti ParlaBO ParlaTO ParlaBZ \
    --output-dir /tmp/kiparla-merged

python tools/translate_metadata.py \
    --input-dir /tmp/kiparla-merged \
    --output-dir KIParla-NoSketch-Data/metadata/KIParla \
    --translations KIParla-NoSketch-Data/translations.tsv

python tools/tsv2vert_v2.py \
    --base-url http://localhost:10071/corpus \
    --artifacts-base-url https://kiparla.github.io/KIParla-artifacts \
    KIParla-NoSketch-Data/metadata/KIParla/conversations.tsv \
    KIParla-NoSketch-Data/metadata/KIParla/participants.tsv \
    KIP/tsv/*.vert.tsv KIPasti/tsv/*.vert.tsv \
    ParlaBO/tsv/*.vert.tsv ParlaTO/tsv/*.vert.tsv \
    ParlaBZ/tsv/*.vert.tsv > KIParla-NoSketch-Data/KIParla/vertical/source
----

== `tsv2vert_v2.py` options

[cols="1,3", options="header"]
|===
| Option | Effect

| `--base-url`
| Root for `audio_file` links: `<base-url>/player/player.cgi?code=…&begin=…&end=…`.
  Use the audio player host (`http://localhost:10071/corpus` locally,
  `https://search.corpuskiparla.it/corpus` in production). Defaults to the
  production URL.

| `--artifacts-base-url`
| Root for `full_conversation` links:
  `<artifacts-base-url>/<MODULE>/html/<CODE>.html`. Defaults to `--base-url`;
  in practice always `https://kiparla.github.io/KIParla-artifacts`.

| `--artifacts-module`
| The `<MODULE>` segment for artifact links. Defaults to the name of the
  directory containing `conversations.tsv`. For the aggregated `KIParla`
  corpus the script ignores this and maps each conversation code back to its
  real module by prefix (`BOA…`/`TOA…` → `KIP`, `KPC…` → `KIPasti`, etc.).

| `--issues-base-url`
| GitHub org/user for the per-transcription-unit `report_url` link
  (`<issues-base-url>/<MODULE>/issues/new?…`). Defaults to
  `https://github.com/KIParla`. Pass `""` to omit `report_url` entirely.

| `--translations-dir`
| Directory of `<CODE>.translations.json` files. A translated transcription
  unit then gets a `translation` structure attribute. Defaults to a
  `translations/` directory next to each input file's `tsv/` directory, so it
  is picked up automatically when the module has one. See
  xref:schema.adoc#translations[Translations].
|===

The output carries four positional attributes per token line — `word` <tab>
`token_id` <tab> `lemma` <tab> `upos` (`lemma`/`upos` passed through from the
source TSV, empty when absent). Short pauses and non-verbal behaviour are
emitted as the zero-width tags `<pause/>` / `<nvb descr="…"/>` rather than
tokens, `<g/>` marks glue, and each `<conversation>` gets
`linguistic_annotation="yes"`/`"no"`. See
xref:schema.adoc#pauses-and-nvb[Pauses and non-verbal behaviour],
xref:schema.adoc#linguistic-annotation[Linguistic annotation] and
xref:schema.adoc[Corpus schema] for the full format.

== Translation table

`translations.tsv` maps `(table, column, en) → it` and currently covers
conversation `type`, `participants-relationship`, `topic`, `languages`, and
participant `occupation` and `study-level`. `translate_metadata.py` warns on
stderr and passes a value through unchanged when it has no entry.

Add a mapping by appending a tab-separated row:

----
table	column	en	it
----

See the xref:tools::scripts.adoc[tools scripts documentation] for the full
reference of all three scripts.
