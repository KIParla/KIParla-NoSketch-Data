= Corpus schema

This page defines the expected structure of vertical files and registry files for KIParla corpora.
Follow this schema when adding a new module.

== Vertical file format

The vertical file is a plain UTF-8 text file with one token per line and XML-like structure tags.
It is produced by `tsv2vert.py` from https://github.com/KIParla/tools[KIParla/tools]
from module `.vert.tsv` files and Italian-translated metadata.

=== Structure

Each conversation is wrapped in a `<doc>` element containing a single `<conversation>` element.
Inside the conversation, each speaker turn is a `<annotation>` element containing one token per line.
Every annotation ends with `//` (Jefferson turn-final marker) before the closing tag.

[source,xml]
----
<doc doc_number="BOA1001" full_conversation="https://..." full_jefferson="https://...">
<conversation code="BOA1001" type="ricevimento" duration="00:37:20"
    participants_number="2" participants_relationship="asimmetrico"
    moderator="no" topic="libero" year="2018" point="BO"
    participants="BO020,BO026">
<annotation begin="150" end="1633"
    audio_file="https://...&begin=150&end=1633"
    participant_code="BO026" participant_occupation="intell"
    participant_sex="F" files_in_which_participant_appears="BOA1001,BOA1002"
    participant_school_region="basilicata" participant_age_range="56-60">
bene
allora
//
</annotation>
</conversation>
</doc>
----

=== `<doc>` attributes

[cols="1,1,3"]
|===
| Attribute | Example | Notes

| `doc_number`
| `BOA1001`
| Conversation code. Used as `SHORTREF`.

| `full_conversation`
| `https://search.corpuskiparla.it/corpus/conversations/BOA1001.html`
| Link to the full conversation page. Not indexed (`MAXLISTSIZE "0"`).

| `full_jefferson`
| `https://search.corpuskiparla.it/corpus/conversations/BOA1001_jefferson.html`
| Link to the Jefferson transcript. Not indexed (`MAXLISTSIZE "0"`).
|===

=== `<conversation>` attributes

[cols="1,1,3"]
|===
| Attribute | Example | Notes

| `code`
| `BOA1001`
| Conversation code.

| `type`
| `ricevimento`
| Interaction type in Italian. Translated from `conversations.tsv`.

| `duration`
| `00:37:20`
| HH:MM:SS. Not indexed (`MAXLISTSIZE "0"`).

| `participants_number`
| `2`
| Integer count.

| `participants_relationship`
| `asimmetrico`
| `simmetrico` or `asimmetrico`.

| `moderator`
| `no`
| `yes` or `no`.

| `topic`
| `libero`
| `libero` or `fisso`.

| `year`
| `2018`
| Four-digit year.

| `point`
| `BO`
| Collection point (province code).

| `participants`
| `BO020,BO026`
| Comma-separated participant codes. `MULTIVALUE "1"`, `MULTISEP ","`.
|===

=== `<annotation>` attributes

[cols="1,1,3"]
|===
| Attribute | Example | Notes

| `participant_code`
| `BO026`
| Speaker code.

| `begin`
| `150`
| Turn start in milliseconds. Not indexed (`MAXLISTSIZE "0"`).

| `end`
| `1633`
| Turn end in milliseconds. Not indexed (`MAXLISTSIZE "0"`).

| `audio_file`
| `https://...&begin=150&end=1633`
| Audio player URL. Not indexed (`MAXLISTSIZE "0"`).

| `participant_occupation`
| `intell`
| Italian occupation code from `participants.tsv`.

| `participant_sex`
| `F`
| `F` or `M`.

| `files_in_which_participant_appears`
| `BOA1001,BOA1002`
| Comma-separated conversation codes. Not indexed (`MAXLISTSIZE "0"`).

| `participant_school_region`
| `basilicata`
| Birth region (Italian region name). Sourced from `birth-region` or `school-region`.

| `participant_age_range`
| `56-60`
| Age range band.
|===

== Registry file

Each corpus has a registry file at `registry/CORPUS_NAME`.
All registries share the same structure; only the header lines differ.

=== Header

[source]
----
MAINTAINER "caterina.mauri@unibo.it"
INFO       "CORPUS_NAME"
NAME       "CORPUS_NAME"
PATH       '/corpora/CORPUS_NAME/indexed/'
ENCODING   "UTF-8"
LANGUAGE   "Italian"
VERTICAL   '/corpora/CORPUS_NAME/vertical/source'
INFOHREF   "https://www.kiparla.it/"
----

Replace `CORPUS_NAME` with the corpus identifier (e.g. `KIPasti`).

=== MAXLISTSIZE conventions

[cols="1,3"]
|===
| Setting | When to use

| _(not set)_
| Attribute is filterable and appears in frequency distributions. Use for categorical metadata: `type`, `year`, `occupation`, `sex`, `region`, `age_range`, relationship, topic, moderator.

| `MAXLISTSIZE "0"`
| Attribute exists for display or linking only. Use for URLs, timestamps, and free-form lists: `audio_file`, `begin`, `end`, `duration`, `full_conversation`, `full_jefferson`, `files_in_which_participant_appears`.
|===

=== SUBCORPATTRS

The `SUBCORPATTRS` line lists the attributes available as subcorpus filters in the UI.
It must not include attributes with `MAXLISTSIZE "0"`.

Current value:

[source]
----
SUBCORPATTRS "conversation.type,conversation.participants_number,conversation.participants_relationship,conversation.moderator,conversation.year,conversation.point,conversation.participants,annotation.participant_occupation,annotation.participant_sex,annotation.participant_school_region,annotation.participant_age_range"
----

== Adding a new module

. Generate the vertical file following xref:generate.adoc[Generating vertical files].
. Copy `registry/KIP` to `registry/NEW_MODULE` and update the four header lines (`INFO`, `NAME`, `PATH`, `VERTICAL`).
. Create `NEW_MODULE/vertical/` and place the vertical file at `NEW_MODULE/vertical/source`.
. Add the new corpus to xref:index.adoc[the corpus list].
. Register it in `docs-site/antora-playbook.yml` if the module has its own documentation component.
. Compile with `make execute CMD="compilecorp --no-ske --recompile-corpus NEW_MODULE"`.
