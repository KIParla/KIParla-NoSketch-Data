= Runtime and deployment

KIParla corpora are compiled and served with
https://github.com/KIParla/NoSketch-Engine-Docker[KIParla/NoSketch-Engine-Docker],
a fork of https://github.com/ELTE-DH/NoSketch-Engine-Docker[ELTE-DH/NoSketch-Engine-Docker].
The fork keeps the upstream image and runtime model and adds KIParla-specific
`make` targets and defaults (see <<what-the-fork-changes>>).

The public instance is https://search.corpuskiparla.it/.

== What you need

* Docker (https://www.docker.com/get-started/[Docker Desktop] on macOS/Windows).
* A checkout of `KIParla/NoSketch-Engine-Docker`.
* A checkout of this repository (`KIParla-NoSketch-Data`), with the
  `<CORPUS>/vertical/source` files already generated — see
  xref:generate.adoc[Generating vertical files]. Check with
  `make check-corpora CORPORA_DIR=…` (below).

== Local workflow

Everything runs from inside the `NoSketch-Engine-Docker` checkout. The fork
reads the corpora from whatever `CORPORA_DIR` points at, so this repository does
*not* need to be copied into `corpora/`.

[source,bash]
----
cd NoSketch-Engine-Docker

# 1. Get the image
make pull                       # or: make build

# 2. Point at the data and see what is ready
export CORPORA_DIR=/path/to/KIParla-NoSketch-Data
make check-corpora
#   KIP: ready
#   KIPasti: ready
#   ...
#   ParlaBZ: missing vertical/source

# 3. Compile
make compile-kip                # one corpus  (KIP KIPasti ParlaBO ParlaTO ParlaBZ KIParla)
make compile                    # every corpus with a file in registry/

# 4. Serve
make run PORT=10070
# → http://localhost:10070/
----

`make run` binds `CORPORA_DIR` to `/corpora` in the container and host `PORT`
to container port 80. `make stop` stops it; `make connect` opens a shell in the
running container; `make execute CMD="…"` runs an arbitrary NoSketch CLI command
(e.g. `corpinfo -s KIP`).

[WARNING]
====
`make clean` removes the image *and* runs `sudo rm -rf $CORPORA_DIR/*/indexed/`
— it deletes every compiled index under whatever `CORPORA_DIR` is currently set
to. Recompiling from the `vertical/source` files rebuilds them.
====

=== Compiled output

Compilation writes the index to `<CORPUS>/indexed/` inside `CORPORA_DIR`. Those
directories are git-ignored in this repository — only `vertical/source`,
`registry/` and `metadata/` are tracked. Large `vertical/source` files are
stored with Git LFS.

== Production deployment

`docker-compose.yml` runs the same image behind a
https://traefik.io/[traefik] proxy that terminates HTTPS with Let's Encrypt,
and optionally a Shibboleth SP. Required environment (see
`secrets/env.sh.template`):

[cols="1,3", options="header"]
|===
| Variable | Purpose

| `CORPORA_DIR`     | Host path bind-mounted to `/corpora`
| `SERVER_NAME`     | Public URL, e.g. `https://search.corpuskiparla.it/`
| `SERVER_ALIAS`    | Host name for the traefik router rule
| `LETS_ENCRYPT_EMAIL` | ACME contact address
| `CITATION_LINK`   | "cite this corpus" link (defaults to the fork's repo)
| `HTACCESS` / `HTPASSWD` | Optional basic auth (`make htpasswd USERNAME=… PASSWORD=…`)
| `PRIVATE_KEY` / `PUBLIC_KEY` | Optional Shibboleth SP cert (`make create-cert`)
|===

[source,bash]
----
source secrets/env.sh
docker compose up -d
----

Corpora are compiled the same way as locally (`make compile` / `make
compile-<name>` against the production `CORPORA_DIR`) before or after the stack
is up; the server picks up a corpus as soon as its `indexed/` directory exists.

[#what-the-fork-changes]
== What the fork changes vs upstream

[cols="1,3", options="header"]
|===
| Area | Change

| `make` targets
| Adds `check-corpora` and `compile-kip` / `compile-kipasti` / `compile-parlabo`
  / `compile-parlato` / `compile-parlabz` / `compile-kiparla`. A `preflight`
  check guards every target and fails early if `CORPORA_DIR` or
  `CORPORA_DIR/registry` is missing.

| Defaults
| `PORT` defaults to `10070`; `CITATION_LINK` points at the KIParla repo.

| Data
| `corpora/` no longer holds the KIParla data — it lives in this repository and
  is referenced through `CORPORA_DIR`. Only the upstream sample corpora
  (`susanne`, `emagyardemo`) remain in the fork.

| Corpora
| Registry files for `KIP`, `KIPasti`, `ParlaBO`, `ParlaTO`, `KIParla`, with
  Italian UI labels, the `token_id` positional attribute, a `<g/>` glue
  structure, and the KIParla `player.cgi` audio links.
|===

The upstream image, `Dockerfile`, `docker-compose.yml`, `conf/` (Apache,
Shibboleth, `compile.sh`) and the example recipes under `examples/` are
unchanged.

== Corpus paths inside the container

[cols="1,2", options="header"]
|===
| Registry setting | Path

| `PATH` (compiled index) | `/corpora/<CORPUS>/indexed/`
| `VERTICAL` (source)     | `/corpora/<CORPUS>/vertical/source`
|===

These are already correct in every file under `registry/`.
